# Workshop

Physical measurement, fabrication and build logs live here.

- `measurement-protocols/` — repeatable ways to measure culms and assemblies.
- `fabrication/` — bow forming, cross-members, lashings, deck/mat and later jigs.
- `logs/` — dated workshop observations.

Distinguish measurement tools from final-construction constraints. Modern scales, cameras or sensors may be useful research instruments even if the intended craft uses simple materials.
