# Parafang reference photos

30 photos of the Parafang bamboo raft, taken 2026-09-23 (Samsung Galaxy A07 5G).
They show the lashings, the woven deck, the bow crossbars and the weathering of the bamboo.

Resized for the repo: long edge 2560 px, JPEG quality 88, 4:4:4 chroma, EXIF orientation applied.
The full-resolution originals (4080×2296) are kept locally, outside the repo.
Use these for visual reference; crop from the originals if a texture map needs more resolution.
