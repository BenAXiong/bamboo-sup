# Craft context

This area holds source-grounded construction context rather than simulator assumptions.

Relevant starting context from the current project work includes Laway / IRA2 and broader East Coast Amis bamboo-raft practice: parallel flotation culms, smaller transverse bamboo, rattan lashings, iterative flotation/load testing, and deliberately upward-curved forward sections. The documented process also makes clear that whole-culm fire bending has real cracking and shape-retention constraints.

Do not silently turn comparative Amis practice into a Laway-specific rule. Preserve provenance when detailed notes or source documents are imported here.
