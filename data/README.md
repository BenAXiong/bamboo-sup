# Data

`data/` is for measured or externally sourced values, not design wishes.

## Rules

- Preserve raw measurements.
- Record units in headers/metadata.
- Do not hide workshop measurements in source code.
- Record how a value was obtained when precision matters.
- Derived/cleaned data must remain traceable to raw values.

Current areas:
- `culms/` — physical bamboo inventory.
- `experiments/` — flotation, heel, trim, water uptake and later bending tests.
