# Designs

A design is an intended, reproducible geometry/configuration — not a screenshot or Three.js scene.

Each meaningful concept should receive an ID such as `SUP-001` and eventually a canonical `design.json` containing culm selection/placement, bow geometry, assembly masses and design load.

- `concepts/` — alternatives and explorations.
- `current/` — current working design pointer/snapshot.

Physical prototypes copy/freeze the exact design actually built under `prototypes/Pxxx/`.
